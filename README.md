# Studentu Vērtējuma Kalkulators

Vienkārša React SPA lietotne, kas aprēķina studenta gala rezultātu pēc
svērtajiem vērtēšanas kritērijiem.

## Palaišana

```bash
npm start
```

## Produkcijas būve

```bash
npm run build
```

## GitHub Pages

Projektā ir iestatīts `"homepage": "."`, tāpēc būves faili izmanto relatīvus
ceļus un ir piemēroti publicēšanai GitHub Pages.
